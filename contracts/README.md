# SiteGuard AI

## Construction Milestone Adjudicator powered by GenLayer

SiteGuard AI is an Intelligent Contract that evaluates construction project milestones using AI-based adjudication.

It helps determine whether submitted construction evidence supports:

- APPROVED
- REJECTED
- NEEDS_REVIEW

## How It Works

1. A project name is submitted.
2. A construction milestone is submitted.
3. Contractor evidence is submitted.
4. AI evaluates the evidence.
5. GenLayer consensus helps reach the final decision.

## Example

### Project
Wind Turbine Foundation

### Milestone
Reinforcement and Anchor Cage Installation

### Evidence
Rebar fixing completed. Anchor cage installed and aligned.
Cover blocks provided and inspection completed.

### Result
APPROVED

## Why GenLayer?

Construction decisions can involve incomplete or ambiguous information.

SiteGuard AI uses GenLayer Intelligent Contracts to evaluate natural-language construction evidence and produce an adjudicated result.
